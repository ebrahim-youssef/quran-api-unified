## ما هذا المزوّد

واجهةٌ ثابتةٌ سريعة تُقدَّم من حافة الشبكة (Edge)، وتُرجِع للآية الواحدة نصَّها وصوتها معًا
في ملفّ JSON واحد. مناسبةٌ حين يهمّك زمنُ الاستجابة.

## نقاط النهاية المستعملة

الرابط الأساس: `https://quranapi.pages.dev/api`

- **النصّ والصوت (آية):** `GET /{surah}/{ayah}.json` — ملفٌّ واحدٌ يحمل الاثنين.

## بنية الاستجابة الخام

```json
{
  "surahNo": 1,
  "ayahNo": 1,
  "arabic1": "بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ",
  "english": "In the name of Allah...",
  "surahNameArabic": "الفاتحة",
  "audio": {
    "1": {
      "reciter": "Mishary Rashid Al-Afasy",
      "url": "https://the-quran-project.github.io/Quran-Audio/Data/1/1.mp3",
      "originalUrl": "https://..."
    }
  }
}
```

`audio` كائنٌ مفتاحُه معرّفٌ رقميٌّ للقارئ.

## التحويل إلى البنية الموحّدة (والسبب)

**النصّ → `UnifiedVerse`:**

| الحقل الموحّد                 | المصدر الخام                  | ملاحظة              |
| ----------------------------- | ----------------------------- | ------------------- |
| `key`                         | `` `${surahNo}:${ayahNo}` ``  | مفتاح `سورة:آية`    |
| `id`                          | `ayahNo`                      | رقم الآية في السورة |
| `text`                        | `arabic1`                     | النصّ العربي        |
| `source`                      | `"Quran API (Edge)"`          | ثابت                |
| `meta.surah` / `meta.english` | `surahNameArabic` / `english` | إضافات              |

**الصوت → `UnifiedAudio`:** يختار المُحوّل قارئًا (المطلوب بالمعرّف، وإلا أوّل مفتاح في
`audio`)، فيأخذ `url` و`reciter` منه، و`scope` = `ayah`، ويحفظ `reciterId` و`originalUrl`
في `meta`.

نستعمل `arabic1` للنصّ الأساس؛ و`arabic2` (إن وُجد) صيغةٌ بديلة تُترك في `meta` عند الحاجة.
