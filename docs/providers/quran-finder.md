# Quran Explorer (Quran Finder) — مرجع المزوّد

**العربية** · [English](/en/providers/quran-finder)

- **المعرّف:** `quran_finder` · **ملف المُحوّل:** `src/adapters/quran-finder.ts`
- **الصفحة الرئيسية:** https://quran-finder.com
- **المحتوى:** نصّ (خام) · **الاعتماد:** لا شيء · **يحتاج وسيطًا:** نعم (CORS)

## ما هذا المزوّد

مصدرٌ يُقدّم النصّ من ملفّات ثابتة، فيجمع بين السرعة وأمان النموذج الساكن. يُرجِع نصًّا
صرفًا لا JSON.

## نقاط النهاية المستعملة

الرابط الأساس: `https://api.quran-finder.com`

- **النصّ (آية):** `GET /text/ar/{surah}/{ayah}/` — يعيد نصّ الآية سلسلةً خام.

## بنية الاستجابة الخام

```
بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ
```

الاستجابة سلسلةٌ نصّية مباشرة؛ لذا يضبط المُحوّل `responseType: 'text'`.

## التحويل إلى البنية الموحّدة (والسبب)

**النصّ → `UnifiedVerse`:**

| الحقل الموحّد | المصدر                               | ملاحظة                                          |
| ------------- | ------------------------------------ | ----------------------------------------------- |
| `key`         | `` `${query.surah}:${query.ayah}` `` | يُبنى من **الطلب**، إذ لا تحمل الاستجابة موضعًا |
| `id`          | `` `${query.surah}:${query.ayah}` `` | لا معرّفٌ عامّ من المصدر                        |
| `text`        | السلسلة الخام (بعد `trim`)           | نصّ الآية                                       |
| `source`      | `"Quran Explorer"`                   | ثابت                                            |
| `meta.type`   | `"raw"`                              | إشارةٌ إلى أنّ الأصل نصّ خام                    |

نبني `key` و`id` من الطلب لأنّ الاستجابة نصٌّ فحسب، بلا رقم آيةٍ ولا جزءٍ ولا صفحة.

## الاعتماد

لا يلزم. والنداءُ من المتصفّح يحتاج **وسيطًا** لتجاوز CORS، فيضع المُحوّل `useProxy: true`.

## حدود المعدّل والخصوصيات

يعيد **نصًّا خامًا** لا JSON — فانتبه في التحليل. ملفّاته ثابتةٌ سريعة، ولا يوفّر بياناتٍ
موضعية.

الانحراف عبر `pnpm test:live`.
